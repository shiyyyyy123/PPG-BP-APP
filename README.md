# README

This project is a **PPG (Photoplethysmography)** signal acquisition and analysis application built for the Android platform. The app uses a smartphone's camera and flashlight to collect PPG signals from the user's fingertip. It offers real-time signal processing and signal quality detection functionalities, making it suitable for research and development in non-invasive physiological parameter monitoring.

---

## Known Issues and Limitations

- **UI Experience Needs Improvement**  
  Some interface interactions and guidance are not yet user-friendly. Further refinements to enhance user experience are planned for future updates.

- **Limited Signal Anomaly Handling**  
  The handling of anomalies such as improper fingertip contact, excessive or insufficient lighting conditions is not yet comprehensive, which may affect signal quality.

- **Algorithm Optimization Potential**  
  The current signal processing and stability detection algorithms are relatively basic. More intelligent signal quality assessment and noise suppression methods are planned for future implementation.

- **Limited Compatibility Testing**  
  The app has been tested on a selection of Android devices but has not yet been validated across all brands and system versions.
